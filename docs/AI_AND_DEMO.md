# Echoes of Arcana — инструкция участника №1

## Сбор голосов и обучение

1. Каждый из трёх участников открывает [браузерный рекордер](../ai_voice/web_recorder.html) в Chrome и вводит свой ID латиницей. Если браузер блокирует микрофон у локального файла, запустите `python3 -m http.server 8000` из папки `ai_voice` и откройте `http://localhost:8000/web_recorder.html`.
2. Каждый записывает по 10 клипов каждого класса. Для `Вирдан`, `Ноктар` и `Таргум` сделайте по три обычных и громких дубля и по четыре шёпотом. Для `background` запишите тишину, шум комнаты и речь без заклинаний. Прослушайте записи и удалите обрезанные дубли.
3. Сложите WAV в одну папку, сохранив имена файлов, и из корня проекта выполните `python3 ai_voice/pack_dataset.py --import-dir /путь/к/WAV`. В сводке проверьте 25–30 принятых клипов на класс и наличие всех трёх участников. Сырые записи храните внутри команды.
4. Откройте [ноутбук](../ai_voice/train_in_colab.ipynb) в Colab, выберите GPU T4, поставьте `UPLOAD_CUSTOM_ZIP = True` и загрузите `ai_voice/dataset_raw.zip`. При необходимости задайте `HOLDOUT_SPEAKER` до обучения. Прогон проверяет переносимость на один ранее не слышанный моделью голос из команды.
5. Распакуйте `voice_training_artifacts.zip`. Замените `ai_voice/spell_model.onnx` полученной моделью после проверки в игре. Для отчёта и слайдов используйте `val_accuracy.png`, `confusion_matrix.png` и `training_metrics.json` из того же запуска.

В `main` уже есть модель, обученная на стартовом датасете. Указанные в коммите 91,67% относятся к той валидации. Результат командного датасета появится после нового прогона. [Коммит базовой модели](https://github.com/Alizhan2/Game-x/commit/912a6aa3c384b84913619fcafefb3f098371df24)

## Проверка на Mac

Откройте игру в Godot и запустите симуляцию из корня репозитория. Колонки громкости и таймер тишины приходят по UDP на `127.0.0.1:5055`.

```bash
python3 ai_voice/voice_engine.py --simulate
python3 ai_voice/voice_engine.py --simulate-adaptive
```

Для микрофона используйте Python 3.11 или 3.12. Установка библиотек и загрузка модели Silero требуют доступа к сети. После этого захват и распознавание работают локально.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install numpy onnxruntime sounddevice
.venv/bin/python ai_voice/voice_vad.py
.venv/bin/python ai_voice/voice_engine.py --calibrate-only
.venv/bin/python ai_voice/voice_engine.py --skip-calibration --vad silero
```

| Проверка | Ожидаемый результат |
|---|---|
| Каждое слово обычным голосом | Один правильный каст на произнесение |
| `Ноктар` шёпотом | Каст шёпотом с громкостью ниже `0.28` |
| Фон без заклинаний | Кастов нет |
| Тишина в финальной развилке | Таймер достигает 5 секунд |
| Push-to-Talk в Godot | При включённом режиме каст проходит, если держать `V` до срабатывания |
| Микрофон отключён | Касты и шёпот с клавиатуры, концовка с удержанием `0` |

Передайте партнёру [инструкцию по сборке на Windows](../ai_voice/BUILD_WINDOWS.md).

## Съёмка и сдача

- Для ролика на 90 секунд используйте 0:00–0:15 на завязку, 0:15–0:40 на голосовой каст и HUD, 0:40–1:10 на контр-щит и смену школы, 1:10–1:30 на развилку. Оставьте слышимым произнесённое заклинание и реакцию игры.
- После объявления слов 3 декабря в 13:00 заполните слоты договора, Зала Эльфов и Гримуара. Согласуйте текст для HUD и диалогов с участниками №2 и №3. Сделайте скриншот каждого места.
- Для PDF/DOCX соберите 5–15 скриншотов, фактические метрики и список предзаготовок. Используйте [шаблон отчёта](../PROJECT_DOCS_TEMPLATE.md) и [реестр лицензий](../ASSETS_LICENSES.md).
- После проверки Windows-билда подготовьте страницу и загрузку на `qwrt.ca`, видео MP4, презентацию в PDF/PPTX и ссылки для Google-формы. Дедлайн пакета по [задаче №5](https://github.com/Alizhan2/Game-x/issues/5) — 5 декабря, 13:00 по местному времени.
